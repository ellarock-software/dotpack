# Support

Thanks for using dotpack. Here's how to get help.

## Questions and ideas

- **GitHub Discussions** — <https://github.com/ellarock-software/dotpack/discussions>
  for questions, ideas, and general discussion.
- **Documentation** — the schema reference and architecture decisions live in
  [`docs/`](docs/) and on the project documentation site.

## Bugs and requests

Search [existing issues](https://github.com/ellarock-software/dotpack/issues)
first, then open one using a template:

- [Bug report](https://github.com/ellarock-software/dotpack/issues/new?template=bug_report.yml)
- [Feature request](https://github.com/ellarock-software/dotpack/issues/new?template=feature_request.yml)
- [Adapter request](https://github.com/ellarock-software/dotpack/issues/new?template=adapter_request.yml)
  (support for a new agent host)

## Security

Please do **not** open public issues for security vulnerabilities. Follow the
process in [SECURITY.md](SECURITY.md).

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md), including the guide for adding a new
host adapter.
